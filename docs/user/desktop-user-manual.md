# Prompt Optimizer Desktop User Manual

## 1. Welcome

Welcome to the Prompt Optimizer desktop app! This app is designed to give you a smooth, barrier-free prompt optimization experience, so you can focus on creating high-quality prompts without worrying about network configuration.

The biggest difference from the web version is that the desktop version **can call the APIs of major AI providers directly, with no proxy or complicated setup**.

## 2. Installation and Launch

### System Requirements

-   Windows 10/11, macOS, or Linux
-   A stable network connection (for API calls)

### Installation Steps

1.  Download the installer for your operating system from the designated release page (for example, Windows users download the `.exe` file).
2.  Double-click the installer and follow the on-screen prompts to complete the installation.
3.  After installation, find the "Prompt Optimizer" icon on your desktop or in your application list and launch it.

## 3. First-Time Setup: Connect Your AI Service

For the app to work, you need to provide an API key for at least one AI provider.

1.  After launching the app, click the **"Model Management"** icon in the sidebar.
2.  On the Model Management page, you will see a list of models. Choose the provider you want to use (such as OpenAI, DeepSeek, etc.).
3.  In the corresponding input box, **enter your API Key**.
4.  Click the **"Test Connection"** button. If the key is valid and the network is working, you will see a "Connection successful" message.
5.  Make sure the **"Enable"** switch next to the model you want to use is turned on.

## 4. Basic Usage

1.  **Enter content**: In the "Content to Optimize" input box on the left, enter the original prompt or text you want to optimize.
2.  **Choose a template**: In the "Optimization Template" dropdown at the top, choose an optimization strategy. For most cases, "General Optimization" is a good place to start.
3.  **Click Optimize**: Click the **"Optimize"** button in the middle.
4.  **View the result**: The "Optimization Result" area on the right will display the optimized prompt generated by the AI.

## 5. FAQ

**Q1: Nothing happens or an error appears after I click "Optimize". What should I do?**

**A:** Please troubleshoot with the following steps:
1.  Make sure your computer is connected to the internet.
2.  Go to the "Model Management" page and click "Test Connection" again to confirm that your API key is still valid.
3.  Confirm that the model used by the optimization template you selected is enabled and configured correctly.

**Q2: The app window is blank?**

**A:** This may be caused by a failure to load app resources. Please try fully closing the app and restarting it. If the problem persists, consider reinstalling the app.

**Q3: Can I use multiple AI providers at the same time?**

**A:** Yes. You can configure and enable multiple providers and models in "Model Management". When using the app, you can choose which model to use for optimization in "Optimization Template" or the related settings.

**Q4: Is my API key safe?**

**A:** Yes. In the desktop version, your API key is stored only on your local computer, and it is sent directly to the corresponding AI provider only when you initiate an optimization request. It does not pass through any third-party server.
