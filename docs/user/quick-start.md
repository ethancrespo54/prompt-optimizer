# Quick Start Guide

## 🚀 Welcome to Prompt Optimizer

Prompt Optimizer is an intelligent tool that helps you turn ordinary prompts into more professional and effective versions.

## ⚡ 5-Minute Quick Start

### 1. Configure an AI Model
1. Click the **⚙️ Model Management** button in the top right corner
2. Enter your API key (OpenAI, Claude, or Gemini)
3. Click **Test Connection** to make sure the configuration is correct
4. Click **Save** to finish the configuration

### 2. Start Optimizing Prompts
1. Enter your original prompt in the input box on the left
2. Choose an optimization mode (System Prompt Optimization / User Prompt Optimization)
3. Choose a suitable optimization template
4. Click the **Start Optimization** button
5. Wait for the AI to generate the optimization result

### 3. View and Use the Results
1. View the optimized prompt on the right
2. Read the reasoning process to understand how the optimization works
3. Click **Favorite** to save high-quality optimization results
4. Click the **Copy** button to copy the result
5. If it needs further improvement, use the **Continue Optimizing** feature

## ❓ FAQ

### Q: Where do I get an API key?
**A:** 
- **OpenAI**: Visit platform.openai.com to sign up and get an API key
- **Claude**: Visit console.anthropic.com to get an API key
- **Gemini**: Visit ai.google.dev to get an API key

### Q: What should I do if optimization fails?
**A:** 
1. Check that your network connection is working
2. Confirm that the API key is valid and has enough quota
3. Try a different model
4. Simplify the original prompt

### Q: How can I improve the optimization quality?
**A:** 
1. Provide a more detailed original prompt
2. Choose a more suitable optimization template
3. Use the iterative optimization feature to refine the result
4. Try different AI models

### Q: Is my data safe?
**A:** 
- All data is stored in your local browser
- It is never uploaded to our servers
- You can export or delete your data at any time
- API calls connect directly to the AI provider

## 🔧 Troubleshooting

### Interface Issues
- **Page won't load** - Refresh the browser or clear the cache
- **Buttons are unresponsive** - Check that your browser supports modern web standards
- **Display problems** - Try adjusting the browser zoom level

### Feature Issues
- **Optimization timeout** - Check your network connection and try optimizing again
- **Results not showing** - Wait longer or refresh the page
- **History lost** - Check whether your browser allows local storage

### Performance Issues
- **Running slowly** - Close other browser tabs to free up memory
- **High memory usage** - Periodically clear history and cache
- **Slow responses** - Check your network speed and the API service status
